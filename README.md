## 📖 项目简介

Visual Studio Code(简称 VS Code)是微软开源的轻量级却功能强大的源代码编辑器,本仓库即其开源上游 "Code - OSS"。它把简洁的代码编辑体验与开发者的核心"编辑—构建—调试"工作流结合起来,提供完善的代码编辑、导航与理解支持、轻量级调试能力以及丰富的扩展模型。

VS Code 每月更新,持续带来新功能与缺陷修复,可运行于 Windows、macOS 和 Linux,是全球最受欢迎的开发工具之一。本仓库提供其官方 README 的中文翻译,方便中文开发者快速了解与上手。

## ✨ 主要特性

- 🔍 **完善的代码编辑与导航**:语法高亮、IntelliSense 智能补全、代码跳转与理解支持
- 🐞 **轻量级调试**:内置调试器,覆盖核心 edit-build-debug 循环
- 🧩 **丰富的扩展模型**:海量扩展,支持几乎所有语言、运行时与平台
- 📦 **内置扩展集**:仓库自带大量语言的语法与片段支持,`*-language-features` 系列提供富语言支持
- 🔄 **月度迭代节奏**:路线图、迭代计划与 endgame 计划全部公开
- 💻 **跨平台**:支持 Windows、macOS 与 Linux
- 🐳 **开发容器支持**:自带 Dev Containers / GitHub Codespaces 开发容器配置,一键搭建开发环境
- 📄 **MIT 开源许可**:源代码对所有人开放

## 🚀 快速开始

**方式一:下载安装版(推荐)**

1. 访问 [VS Code 官网下载页](https://code.visualstudio.com/Download),获取 Windows、macOS 或 Linux 版本;
2. 安装后打开即可使用;
3. 想每天体验最新功能,可安装 [Insiders 版](https://code.visualstudio.com/insiders)。

**方式二:从源码构建**

```bash
git clone https://github.com/microsoft/vscode
cd vscode
npm install
npm run watch
# macOS / Linux
./scripts/code.sh
# Windows
.\scripts\code.bat
```

**方式三:开发容器 / Codespaces**

1. 已安装 VS Code 与 Docker 的前提下,使用 **Dev Containers: Clone Repository in Container Volume...** 命令;
2. 或使用 GitHub Codespaces 扩展执行 **Codespaces: Create New Codespace** 命令;
3. 完整构建建议至少 **4 核 CPU 与 6 GB 内存(推荐 8 GB)**。
